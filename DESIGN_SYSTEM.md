# Maa Sati IAC — Academy Signature Design System

## Visual identity
Professional educational website; original Blue & Gold Maa Sati IAC logo shown at native aspect ratio. Clean ivory/white backgrounds, deep navy headings, royal-blue CTAs and restrained gold accents. No neon-heavy sci-fi visual overload.

## Tokens
- Navy headings: #142842; deep navy: #142b4d
- Royal blue: #2454bd; gold: #c7a05a
- Canvas: #f7f9fd; white surfaces: #ffffff
- Borders: #e4e9f1; supporting text: #637388
- Manrope for headings, DM Sans for body
- Cards 15px radius and subtle shadows; buttons 9px radius
- Desktop content width 1250px; responsive single-column layout on mobile

## Image direction
Every major page uses an appropriate distinct image; course thumbnails are NOT repeated. Web Development: code workspace; App Development: mobile phone/app design; AI: machine intelligence; Data Science: visual analytics; School: learning/classroom; Internship: collaborative teamwork; Student projects: separate concept-specific imagery clearly labeled demo until approved genuine images are provided; Certificates: academic achievement.

## Page standards
Home: premium photographic split hero, quick links, course cards, school & college panels, project showcase, conversion CTA.
Courses: course thumbnails, learning roadmap, prerequisites and inquiry.
School: seminar + 7-day program, lesson journey, project showcase.
Internships: 4 tracks, mentorship stages and apply pathway.
Projects: filtered gallery, student/school attribution only after privacy approval.
Certificates: controlled issuance, verification and download UI.
Student Portal: refined game mechanics (XP, streaks, badges, quizzes) inside uncluttered professional dashboard.
About: real institute story, training philosophy and partner programs.
Future Admin: consistent tables, roles, approvals, moderation and content upload.
AI assistant: accessible help widget, honest distinction between FAQ demo and connected LLM.

## Production limitations
Current deployed frontend contains demo interactions; authentication, real enrollment, private class recordings, payment collection, certificate issuance, secured student records and LLM backend are NOT yet production-ready. Avoid using demo metrics or student identities as factual claims.
