# Maa Sati IAC — Harbor Academy Design System

## Brand and palette
Original blue-and-gold Maa Sati IAC logo, preserved without cropping or redesign and embedded directly in the deployed HTML to prevent missing assets. New low-brightness academic palette: slate-mist canvas #dce4ed to #e8edf1, muted blue-grey panels #dce5ec, deep navy headings #192f49, rich slate-blue actions #315988, muted gold highlights #c1a273, text #4d637d, blue-grey borders #bfcdd8. Avoid pure white in large surfaces and avoid harsh neon glow.

## Layout
Refined professional academy presentation with approachable spacing, clear hierarchy, readable sans-serif typography, rounded 12–20px cards, soft depth, relevant illustrations, light motion, mobile-first stacking. Keep clear focus states and prefers-reduced-motion support.

## Image assets
Fourteen distinct, locally generated vector illustrations: hero, web development, app development, artificial intelligence, data science, school, college, internships, projects, plant monitoring, robotics, certificates, learning portal, about. They are embedded in HTML as self-contained SVG data URLs to avoid failed remote image requests; the original official logo is embedded as base64 WebP. The illustrations are decorative concepts, not authentic photos of enrolled students or actual school projects.

## Page image placement
Home: hero and school/college program images. Courses: unique illustration per discipline. School: classroom-style banner. Internship: teamwork banner. Projects: unique thumbnails for each demo concept. Certificates: certificate artwork. Portal: learning dashboard image. About: institute-style artwork. Maintain useful alternative text.

## Functionality caution
Current site is an interactive frontend demo. Real sign-in, payment, verified certificate issuance, class recordings, student data controls and LLM backend remain pending production integrations. Do not present sample student details or placeholder achievements as authentic.
