# Maa Sati IAC — Sati Technologies Studio Theme

Source reference: Sati Technologies website and connected GitHub repository `satitech-official/satitech-showcase` (particularly `src/app/globals-premium.css`, `src/app/globals-base.css`).

## Exact company-style tokens
- Premium paper: `#f4f1eb`
- Surface: `#fcfaf6`
- Deep ink: `#17212b`
- Muted type: `#697078`
- Hairline border: `#d8d2c8`
- Coral action: `#d75c3e`
- Coral tint: `#f3d7cf`
- Sage supporting tone: `#dce5db`
- Font: Manrope for UI, headings, navigation and body copy. Instrument Serif for editorial/italic highlights.
- Shadow: `0 1.3rem 3.4rem rgba(23,33,43,.08)`
- Buttons: compact pill/rounded corners; restrained hover changes.

## Application
The `sati-brand.css` stylesheet is loaded after the existing inlined IAC styles so the latest brand system takes precedence site-wide across Home, Courses, School Programs, Internships, Student Project Gallery, Certificates, Portal and About. Existing inlined original IAC logo, images, page content, navigation, demo interactivity and mobile structure are retained.

## Caveats
Current site is a frontend demo; authentication, actual enrollment, protected video hosting, production certificate issuance, payments, student data protections and generative AI backend require separate real integrations. Demo content is not a claim about actual learners, projects or partners.
